模板管理

提示词统一存放在 prompts/ 目录，通过文件包上传 / 下载离线编辑。配置项（接口地址、密钥等）通过 CSV 单向上传，加密存储。

1 上传配置 CSV
→
2 上传 Prompt 文件包
→
3 预览 / 下载

步骤 1：上传配置 CSV

格式：key, value, 说明（三列）
已配置的 Key（🔒 项点击眼睛图标查看明文）

步骤 2：上传 Prompt 文件包

文件包目录结构即访问路径。例如 doc/classify.md → 访问路径 doc/classify。新建 hr/recruit.md 即自动生成 hr/recruit 入口。claude-md.md 和 sections/ 不作为访问路径。支持格式：.tar / .tar.gz / .tgz / .zip

首次使用时内置默认模板，上传后下载即为上次上传的内容

步骤 3：预览 / 下载当前模板
